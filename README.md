## Основные скрипты:

- **`17th_iter.py`**  
Основной скрипт, который запускает процесс обучения и оценки модели FRED-T5.  

Запуск:
```bash
python 17th_iter.py
```

- **`load_dataset.py`**  
Скрипт для загрузки данных из JSONL-файлов. Данные для различных задач загружаются на основе указанного префикса.

- **`save_checkpoint.py`**  
Скрипт для преобразования чекпоинта модели (сохранённого в формате `.pth`) в формат Hugging Face для последующего использования:
  - загружает базовую архитектуру модели;
  - загружает веса из файла чекпоинта (`.pth`);
  - сохраняет полученную модель в формате Hugging Face.

## Папка `rsglue`

В папке `rsglue` находятся скрипты, используемые для подготовки и отправки решений (submission) на бенчмарк Russian SuperGLUE.
