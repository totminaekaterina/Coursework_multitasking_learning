## Основные папки и скрипты:

### Папка `mtlt5_main`

- **`19th_iter_train_val.py`**  
Основной скрипт, который запускает процесс обучения и оценки иерархичной мультизадачной модели FRED-T5.  

Запуск:
```bash
python 19th_iter_train_val.py
```

- **`load_dataset.py`**  
Скрипт для загрузки данных из JSONL-файлов. Данные для различных задач загружаются на основе указанного префикса.

- **`save_checkpoint.py`**  
Скрипт для преобразования чекпоинта модели (сохранённого в формате `.pth`) в формат Hugging Face для последующего использования:
  - загружает базовую архитектуру модели;
  - загружает веса из файла чекпоинта (`.pth`);
  - сохраняет полученную модель в формате Hugging Face.

#### Подпапка `data_10k`

- `train_10k.jsonl` - тренировочные данные.
- `val_1k.jsonl` - валидационные данные.

#### Подпапка `logs_10k`

Папка с логами обучения модели на датасете 10 тыс. тренировочных данных.


#### Подпапка `images`

В папке лежат графики тренировочных и валидационных потерь, полученные после обучения модель на 10 тыс. тренировочных данных (`*_10k.png`) и 900 тыс. данных (`*_1bln.png`).


### Папка `rsglue`

В папке `rsglue` находятся скрипты, используемые для подготовки и отправки решений (submission) на бенчмарк Russian SuperGLUE.

- **`t5_rsglue_full.py`**  
Основной скрипт, который запускает процесс обучения моделей на датасетах бенчмарка Russian SuperGLUE.  

Запуск:
```bash
python t5_rsglue_full.py
```

- **`toolt5_full.py`**  
Скрипт преподготовки датасетов каждой задачи, представленных в бенчмарке.  

- **`validate.py`**  
Скрипт с функциями подсчета метрик на валидационных данных для каждого задачи.


### Папка `prepare_dataset`

В папке находятся скрипты, используемые для создания собственного набора данных с использованием техник автоматической аннотации данных с использованием предварительно обученных моделей из открытых источниковктиков для следующих перечисленных задач:
- Распознавание именованных сущностей (NER), 
- Многоклассовая классификация (Multiclass Classification), 
- Распознавание подразумеваемых отношений (NLI),
- Генерация парафразов (Paraphrase generation), 
- Генерация вопросов (Question Generation, QG),
- Генерация ответов на вопросы (Question Answering, QA), 
- Суммаризация текста (Text summarization),
- Генерация заголовков (Title Generation).

#### Подпапка `GenData`

В этой подпапке размещены скрипты, использующие разные модели для генерации соответствующих меток для перечисленных выше задач.

- **`main.py`**  
Основной скрипт, запускающий генерацию метод для каждой из задач. 

Запуск:
```bash
python main.py
```

- **`fix_data.py`**  
Скрипт для исправления некорректных данных с помощью генеративной модели.

Запуск:
```bash
python fix_data.py
```
